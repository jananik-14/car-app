# Wheels2Drive

A Flutter-based minimal bidding app for a vehicle marketplace, connecting buyers and sellers with an easy-to-use bidding system.

## Project Structure
This app will use a clean architecture with the following structure:
- `lib/screens/`: Contains the 11 main UI screens.
- `lib/widgets/`: Reusable UI components matching the design system.
- `lib/services/`: Placeholder backend service calls for the MERN stack.
- `lib/models/`: Data models for users, vehicles, and bids.
- `lib/theme/`: Global styling, fonts (Plus Jakarta Sans), and colors.

## Tech Stack
- **Frontend:** Flutter (Mobile + Web)
- **State Management:** Provider
- **Routing:** GoRouter
- **Network Calls:** Dio
- **Backend (Target):** MongoDB, Express.js, Node.js (MERN)
